# IoT-система на базе ESP32: Учет посещаемости, видеофиксация и автоматическая отчетность

## О проекте

Данный проект представляет собой IoT-устройство на базе микроконтроллера **ESP32**, предназначенное для комплексного учета посещаемости, видеофиксации событий и автоматического формирования отчетности.

Система работает без необходимости в постоянном подключении к внешнему серверу: все ключевые процессы — от идентификации пользователя до формирования итогового файла — выполняются непосредственно на самом микроконтроллере. Это делает устройство автономным и удобным для развертывания в любом месте, где есть Wi-Fi.

## Как это работает

Работа системы построена на непрерывном цикле обработки событий. Устройство находится в режиме ожидания, пока не произойдет событие (например, идентификация пользователя), после чего запускается цепочка действий.

### 1. Идентификация и фиксация события
Когда пользователь взаимодействует с системой (прикладывает карту), ESP32 мгновенно реагирует:
- Считывает данные с карты.
- Определяет, кто именно зафиксирован.
- Фиксирует точное время события.

### 2. Формирование данных на устройстве
Ключевая особенность проекта — **файл формируется прямо на ESP32**. Это значит, что:
- Данные о посещении записываются в локальное хранилище (SD-карта).
- Запись ведется в структурированном виде, готовом для дальнейшей обработки.
- Устройство не зависит от внешних серверов на этом этапе.

### 3. Видеофиксация
Параллельно с фиксацией события система запускает запись видео:
- Камера начинает запись в момент события.
- Видео сохраняется локально или передается по сети.
- Это позволяет не только отметить факт присутствия, но и иметь визуальное подтверждение.

### 4. Накопление и обработка данных
ESP32 ведет таблицу посещаемости в течение заданного периода:
- Каждое событие добавляется в общую таблицу.
- Система отслеживает, кто пришел, во сколько и сколько времени провел.

### 5. Автоматическая отправка отчета
По завершении периода (или по команде) система:
- Формирует итоговую таблицу посещаемости.
- Подключается к Wi-Fi.
- Отправляет готовый файл на указанную электронную почту.
- После отправки данные могут быть очищены или заархивированы.

##  Функционал системы

### Учет посещаемости
Система посещаемости — центральный элемент проекта. Она позволяет:
- Отслеживать вход и выход пользователей.
- Вести хронологию событий с точностью до секунды.
- Формировать статистику по каждому человеку.
- Работать как в режиме реального времени, так и с накоплением данных.

### Видеофиксация
Видеомодуль обеспечивает:
- Запись видео в момент события.
- Возможность просмотра архива записей.
- Дополнительный уровень контроля и безопасности.

### Управление пользователями
Добавление людей в систему реализовано гибко:
- Новые пользователи могут быть добавлены через веб-интерфейс или файл конфигурации.
- База пользователей хранится на самом устройстве.
- При необходимости список легко обновляется.

### Формирование и отправка таблиц
Один из ключевых сценариев работы:
- Устройство самостоятельно формирует таблицу с данными о посещаемости.
- Таблица приводится к удобному виду (заголовки, столбцы, сортировка).
- Файл автоматически отправляется на почту ответственному лицу.
- Это избавляет от необходимости вручную выгружать данные.

##  Конструкция устройства

Аппаратная часть проекта представляет собой сборку на базе ESP32, включающую:
- Сам микроконтроллер ESP32 .
- Модуль идентификации (RFID/NFC-считыватель).
- Сервопривод.
- Камеру для видеофиксации.
- Модуль SD-карты для хранения видео и файлов.
- Элементы питания и корпус.


##  Типовой сценарий использования

1. Пользователь подходит к устройству и идентифицируется.
2. ESP32 фиксирует событие и запускает видеофиксацию.
3. Данные записываются в локальную таблицу.
4. По завершении периода система формирует отчет.
5. Готовый файл автоматически отправляется на почту.
